# Sol xhigh Research Gallery

This repository publishes a static GitHub Pages site for selected AI-generated consciousness-research papers.

The public site intentionally exposes only papers that satisfy all of these checks:

- `status = published`
- `provenance = live_api`
- `generationModel = gpt-5.6-sol`
- `reasoningEffort = xhigh`

Mock manuscripts, intermediate drafts, and unvalidated records are not included in the published `docs/` site.

GitHub Pages can serve the site from the `/docs` folder on the `main` branch.
