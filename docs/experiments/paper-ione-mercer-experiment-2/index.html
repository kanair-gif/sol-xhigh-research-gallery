Reader Guide

The model shows a weak held-out access signal, but the intervention is dominated by raw YES/NO polarity. The result is useful precisely because it exposes how easily an AI-consciousness assay can confuse access structure with response policy.

Question: Does Qwen3.8-27B carry an access-like internal signal that survives when YES and NO are deliberately reversed across trials?

Boundary: This is evidence about a report-relevant internal variable in an open-weight model, not evidence of phenomenal consciousness, moral status, or self-knowledge.
