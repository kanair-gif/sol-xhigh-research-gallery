Formal Model

1. Augmented delayed process and fixed-policy Koopman operator

Let

\[ G=(V,E) \]

be a finite directed graph. A vertex denotes a selected neural variable at a declared grain, and an edge denotes an effective directed pathway. Neither the graph boundary nor its grain is generated by the theory.

Suppose the measured or latent neural variables follow a delayed stochastic update,

\[ X_v^{n+1}\sim K_v\!\left( \cdot\mid X_v^n, \{X_u^{\,n-d_e}:e=(u,v)\}, U_v^n \right). \]

Let

\[ D=\max_{e\in E}d_e. \]

The displayed current state \(X^n\) is generally not Markov. Define the augmented state

\[ Z^n= \left( X^n,X^{n-1},\ldots,X^{n-D},C^n \right), \]

where \(C^n\) contains any protocol variable needed to make the intervention schedule time homogeneous. Fix a stationary intervention policy \(\pi\), possibly randomized and state dependent. The augmented process then has a Markov kernel

\[ \mathsf K^\pi(dz'\mid z). \]

If interventions change the policy, they define a family \(\{\mathsf K^\pi\}\), not one universal operator. Every theorem below applies to one specified policy and one specified feature representation at a time.

Assume \(\mathsf K^\pi\) has an invariant probability measure \(\nu^\pi\). Its Markov–Koopman operator is

\[ (\mathcal K^\pi f)(z) = \int f(z')\,\mathsf K^\pi(dz'\mid z). \]

On \(L^2(\nu^\pi)\), Jensen’s inequality and invariance imply

\[ \|\mathcal K^\pi f\|_{L^2(\nu^\pi)} \le \|f\|_{L^2(\nu^\pi)}. \]

Thus \(\mathcal K^\pi\) is a bounded contraction. This paper does not interchange Koopman, Perron–Frobenius, and interventional transition operators: only this fixed-policy Markov–Koopman construction is used.

Let \(W=(V_W,E_W)\subseteq G\) be a predeclared weakly connected candidate support. Define the abstract phase-feature Hilbert space

\[ \mathscr H_W = \bigoplus_{v\in V_W} L^2(\mathbb A_F;\mathbb C^{m_v}), \qquad \mathbb A_F=\mathbb R/T_F\mathbb Z. \]

Assume there is a declared isometric feature map

\[ \iota_W:\mathscr H_W\longrightarrow L^2(\nu^\pi;\mathbb C^m) \]

whose range is invariant under \(\mathcal K^\pi\). The laboratory-frame transfer operator is then

\[ \boxed{ \mathcal P_{\mathrm{lab}} = \iota_W^{-1} \mathcal K^\pi \iota_W }. \]

This equation links the spectral operator to the delayed stochastic process. If the fitted feature space is only approximately invariant, then the residual

\[ \epsilon_{\mathrm{cl}} = \|(I-\iota_W\iota_W^*)\mathcal K^\pi\iota_W\| \]

is a model-closure error. Exact theorems do not apply without either setting \(\epsilon_{\mathrm{cl}}=0\) or adding it to the approximation bounds.

2. Phase circle, delays, and gauge

Let \(T_F>0\) be a predeclared front period, circuit time, or episode scale. Define

\[ \mathbb A_F=\mathbb R/T_F\mathbb Z \]

with circular distance

\[ |[s]|_{T_F} = \min_{m\in\mathbb Z}|s-mT_F|. \]

The principal representative is

\[ \operatorname{wrap}_{T_F}([s]) \in(-T_F/2,T_F/2]. \]

Choose one orientation for each edge of the underlying graph realization. Effective delays form a cochain

\[ \tau\in C^1(W;\mathbb A_F). \]

For \(e=(u,v)\), \(\tau_e\) may combine conduction, synaptic, integration, filtering, and phase-reset latency. The scalar additive model is a hypothesis, not a consequence of neural anatomy.

An arrival chart is

\[ a\in C^0(W;\mathbb A_F), \qquad (da)_e=a_v-a_u. \]

A local-clock reparameterization is

\[ c\in C^0(W;\mathbb A_F) \]

acting as

\[ \tau\mapsto\tau^c=\tau+dc, \qquad a\mapsto a^c=a+c. \]

The edge residual is

\[ \rho_e(a) = \operatorname{wrap}_{T_F} \left( \tau_e-(a_v-a_u) \right). \]

Because

\[ (\tau+dc)-d(a+c)=\tau-da, \]

the residual is gauge invariant.

For a signed closed walk \(C\), define

\[ \operatorname{Hol}_\tau(C) = \sum_{e\in C}\epsilon_{C,e}\tau_e, \]

where \(\epsilon_{C,e}=1\) for traversal in the chosen orientation and \(-1\) for reverse traversal.

The obstruction is

\[ \boxed{ h(W) = \min_{a\in C^0(W;\mathbb A_F)} \|\tau-da\|_{\infty,T_F} = \min_a\max_{e\in E_W}|\rho_e(a)| }. \]

The minimum exists because \(C^0(W;\mathbb A_F)\) is compact.

For every cycle \(C\),

\[ d_{T_F}\!\left(\operatorname{Hol}_\tau(C),0\right) \le |C|\,h(W), \]

and therefore

\[ h(W)\ge \max_C \frac{ d_{T_F}(\operatorname{Hol}_\tau(C),0) }{ |C| }. \]

The inequality need not be an equality when several cycles compete for the same edge residuals.

3. Full and operational path categories

The full mathematical result uses all signed paths in the graph realization. Reverse traversal is then an algebraic operation contributing \(-\tau_e\); it need not represent spontaneous reverse neural propagation.

For empirical work, let \(\mathcal R\) be a predeclared collection of comparable path pairs

\[ (p_1,p_2) \]

with common endpoints. Let \(Z_{\mathcal R}\) be the subgroup of integral graph cycles generated by the signed chain differences \(p_1-p_2\). Operational path consistency requires only

\[ \langle\tau,z\rangle=0 \quad \text{for every }z\in Z_{\mathcal R}. \]

If \(Z_{\mathcal R}\) spans the full cycle space, this is equivalent to \(h(W)=0\). Otherwise, operational consistency can hold even when ordinary cellular cohomology is nontrivial. Neural claims involving \(h(W)\) therefore require evidence that the tested route comparisons identify the relevant cycle space.

4. Local chart presheaf and cover condition

For each subgraph \(U\subseteq W\), define

\[ \mathscr S_\tau(U) = \left\{ a_U\in C^0(U;\mathbb A_F): da_U=\tau|_U \right\}. \]

Restrictions make \(\mathscr S_\tau\) a presheaf. When nonempty, \(\mathscr S_\tau(U)\) is a torsor over locally constant \(\mathbb A_F\)-valued functions.

Suppose a cover \(\{U_\alpha\}\) admits local charts \(a_\alpha\). On overlaps,

\[ g_{\alpha\beta}=a_\beta-a_\alpha \]

is locally constant and satisfies

\[ g_{\alpha\beta} + g_{\beta\gamma} + g_{\gamma\alpha}=0. \]

Thus the overlap constants form a Čech \(1\)-cocycle governing descent. For an arbitrary subgraph cover, this descent statement remains valid, but the resulting Čech class cannot automatically be identified with cellular \(H^1(W;\mathbb A_F)\).

That identification is used only when the geometric realization \(|W|\) is equipped with a good or Leray cover whose nonempty finite intersections are contractible, or after passage to a refinement for which the standard Čech–cellular comparison theorem applies. Because a graph has no \(2\)-cells, every cellular \(1\)-cochain is a cocycle, and

\[ H^1(W;\mathbb A_F) = C^1(W;\mathbb A_F)/dC^0(W;\mathbb A_F). \]

The scalar \(h(W)\) is a metric distance to the exact cochains; it is not itself a cohomology class or group.

8. Spectral cluster, decay, and metastability

Let \(\Gamma\) be a predeclared positively oriented contour in the resolvent set of \(\mathcal P_F\). The associated Riesz projector is

\[ \Pi_F = \frac{1}{2\pi i} \oint_\Gamma (zI-\mathcal P_F)^{-1}\,dz. \]

The selected cluster is a **scalar decaying resonance** when

\[ \mathcal P_F\Pi_F = \Pi_F\mathcal P_F = \lambda_F\Pi_F, \qquad 0<|\lambda_F|<1, \]

and \(\Pi_F\) has finite nonzero rank.

Write

\[ \lambda_F=e^{-\kappa+i\omega}, \qquad \kappa=-\log|\lambda_F|>0. \]

Decay alone is not metastability. Choose before fitting:

  • a minimum retention horizon \(N_{\mathrm{meta}}\ge2\);
  • a minimum retained-amplitude fraction \(\eta_{\mathrm{meta}}\in(0,1)\).

The resonance is **episode-metastable** only if

\[ |\lambda_F|^{N_{\mathrm{meta}}-1} \ge \eta_{\mathrm{meta}}. \]

A stationary mode with \(|\lambda_F|=1\) is a separate boundary class, not an admissible decaying resonance. Modes with \(\lambda_F=0\) or \(|\lambda_F|>1\) are also excluded.

Traveling-wave existence does not imply spectral stability. Periodic traveling waves can exist while their linearized spectrum is unstable in non-neural systems [@src-paper-mateo-orlov-8-arxiv-25]. Wave detection and spectral selection must therefore remain separate empirical tasks.

For a real operator, a nonreal \(\lambda_F\) is accompanied by its conjugate under the usual reality assumptions. The complex formulation represents an analytic component. A real reconstruction uses

\[ \Pi_F^{\mathbb R} = \Pi_{\lambda_F}+\Pi_{\overline{\lambda_F}} \]

and a two-dimensional rotation-decay block. The scalar eigen-relation above then applies to each complex component, not to the real pair as one scalar eigenspace.

**A1. Fixed front locality.**

\[ B_F = S_{W,\sigma}B_F = B_FS_{W,\sigma}. \]

The first equality localizes the selected range; the second makes the operator insensitive to inputs outside the declared tube.

**A2. Clock-gauge covariance.**

\[ B_F[\tau+dc,\mathcal P_{\mathrm{lab}}^c,S^c,p^c] = U_cB_F[\tau,\mathcal P_{\mathrm{lab}},S,p]U_c^{-1}. \]

**A3. Formal edge-decoder consistency.** For every edge \(e=(u,v)\),

\[ \delta_v^{B_F} \!\left( B_F\mathsf T_ep_u(r) \right) = \delta_u^{B_F} \!\left( B_Fp_u(r) \right) + \tau_e. \]

Because the decoders return circle values, the equality is in \(\mathbb A_F\).

**A4. Declared path independence.** For every declared comparable path pair \(p_1,p_2:u\leadsto v\),

\[ B_F\mathsf T_{p_1}p_u(r) = B_F\mathsf T_{p_2}p_u(r). \]

The full mathematical class uses all signed path pairs. The neural operational class may use only \(\mathcal R\).

**A5. Timing fidelity and nondegeneracy.** For each relevant vertex, \(r\mapsto B_Fp_v(r)\) is continuous, nonzero, nonconstant, and injective. The declared quantitative decoder also satisfies the local timing-discrimination condition.

**A6. Decaying, episode-metastable spectral retention.**

\[ B_F^2=B_F, \]

\[ \mathcal P_{\mathrm{lab}}B_F = B_F\mathcal P_{\mathrm{lab}} = \lambda_FB_F, \]

\[ 0<|\lambda_F|<1, \]

\[ |\lambda_F|^{N_{\mathrm{meta}}-1} \ge\eta_{\mathrm{meta}}, \]

and

\[ \gamma_F = \operatorname{dist} \left( \lambda_F, \operatorname{spec} \left( \mathcal P_{\mathrm{lab}}|_{\ker B_F} \right) \right)>0. \]

The relation \(B_F\mathcal P_{\mathrm{lab}}=\mathcal P_{\mathrm{lab}}B_F\) gives a complementary invariant decomposition

\[ \mathscr H_W = \operatorname{Ran}B_F\oplus\ker B_F. \]

No adjoint invariance is assumed, so this is not called a reducing decomposition.

10. Finite-horizon filters and calibrated defect

Assume

\[ \mathcal P_F^k = \lambda_F^k\Pi_F+R^{(k)} \]

and

\[ \frac{ \|\lambda_F^{-k}R^{(k)}\| }{ \|\Pi_F\| } \le Mq^k, \qquad M\ge1, \quad 0\le q<1. \]

The quantity \(q\) is a relative power-decay factor in this assumed estimate. It is not generally determined by the spectral separation \(\gamma_F\), especially for nonnormal operators.

Define the renormalized filter

\[ \widehat\Pi_L = \frac1L \sum_{k=0}^{L-1} \lambda_F^{-k}\mathcal P_F^k \]

and the phase-corrected, amplitude-unrenormalized filter

\[ \widetilde\Pi_L = \frac1L \sum_{k=0}^{L-1} e^{-ik\omega}\mathcal P_F^k. \]

For approximate charts, let

\[ \mathcal A_\sigma = \left\{ a: \max_e|\rho_e(a)|\le r_0\sigma \right\}. \]

For each edge, let \(\Psi_e(s)\) be the preregistered, calibrated response signature associated with a residual phase \(s\). Assume

\[ c_h\frac{|s|}{\sigma} \le \|\Psi_e(s)-\Psi_e(0)\|_{e,\mathrm{cal}} \le C_h\frac{|s|}{\sigma} \]

in the local regime. Define

\[ \Delta_h(a) = \max_e \|\Psi_e(\rho_e(a))-\Psi_e(0)\|_{e,\mathrm{cal}}. \]

Let \(\Pi_a\) and \(\widetilde\Pi_{L,a}\) be obtained from the same laboratory operator and the same conjugated spectral cluster. Define

\[ G_L(a) = \frac{ \|\widetilde\Pi_{L,a}-\Pi_a\| }{ \|\Pi_a\| }. \]

Because chart changes are unitary conjugacies, these operator norms and the associated constants are invariant when the operator and cluster are held fixed. If the operator is re-estimated separately after each chart fit, uniformity is no longer automatic and must be tested empirically.

The aggregate diagnostic is

\[ \boxed{ D_L = \inf_{a\in\mathcal A_\sigma} \left[ \Delta_h(a)+G_L(a) \right]. } \]

The two nonnegative terms are intentionally added so that phase inconsistency cannot cancel spectral-filter error. \(D_L\) is a calibrated theoretical diagnostic, not a natural distance on neural data, a prediction loss, or a consciousness score.

Evidence at one level does not automatically establish the next.

Connectome topology can influence modeled cortical wave direction and frequency gradients [@src-paper-mateo-orlov-8-crossref-11]. This supports treating propagation direction as a substantive variable, not the inference that waves bind contents.

Phase-response curves and conduction delays interact in synchronization models [@src-paper-mateo-orlov-8-crossref-8]. In this framework, they may contribute to an effective delay model and capture response, but they do not guarantee additive transport or zero cycle holonomy.

The reported audio-visual inter-trial-coherence increase near synchronous stimulation is compatible with phase-sensitive multisensory processing [@src-paper-mateo-orlov-8-crossref-9]. It is not a direct estimate of \(\sigma\), because inter-trial coherence may arise from common drive, evoked responses, or local resetting without directed path-consistent propagation.

Measurement-error model

Let the estimated edge phase be

\[ \widehat\tau_e = \tau_e+\epsilon_e \pmod{T_F}. \]

The error vector \(\epsilon\) should not be assumed independent. Shared input, common timestamp jitter, filtering, source leakage, and common intervention clocks can induce correlated errors. A suitable likelihood may use wrapped multivariate normal, von Mises, or mixture distributions with latent winding integers. Phase unwrapping is then part of inference rather than preprocessing fixed without uncertainty.

A minimal observation model is

\[ Y_{v,t} = H_v(Z^t)+\zeta_{v,t}, \]

where \(\zeta\) may be temporally colored and cross-channel correlated. Timestamp uncertainty can be represented by latent perturbations

\[ t^{\mathrm{obs}}_{v,k} = t^{\mathrm{true}}_{v,k}+\xi_{v,k}. \]

Posterior or bootstrap uncertainty must propagate from \(Y\) and \(\xi\) to:

\[ \tau_e,\quad \operatorname{Hol}_\tau(C),\quad h(W),\quad \lambda_F,\quad \Pi_F,\quad M,\quad q. \]

The exact spanning-tree algorithm below does not solve this statistical problem.

Identification of the augmented operator

The maximum modeled delay \(D\), intervention policy, observable dictionary, regularization, and sampling interval must be fixed on training data. The feature-closure residual \(\epsilon_{\mathrm{cl}}\) should be reported. A fitted operator is inadequate if its apparent resonance disappears under:

  • modest changes of state-history depth;
  • resampling or bootstrap refitting;
  • held-out interventions;
  • reasonable changes of observable basis;
  • contour perturbations that should preserve the same cluster;
  • pseudospectral diagnostics for nonnormal transients.

The contour \(\Gamma\) cannot be chosen solely because it isolates a visually convenient mode. A selection rule should specify minimum rank stability, spatial support, retention, out-of-sample prediction, and separation from matched spectral nulls.

Perturbational prediction

For an intervention at vertex \(v\) and local phase \(\theta_v\), define

\[ \phi_v=\theta_v-a_v. \]

Under \(\mathsf H_N\), interventions matched in \(\phi_v\) should yield more similar projected responses than interventions matched only in laboratory time or instantaneous local phase. Conversely, interventions delivered simultaneously but at different causal phases may be assigned to different tokens.

This is a directional prediction about response geometry. It is not merely a prediction of increased amplitude, phase locking, or evoked power.

Functional stages that remain distinct

The theory does not identify the following stages:

1. recurrent, dendritic, thalamocortical, or other interactions generate the augmented transition dynamics; 2. a front-supported resonance retains a phase-consistent packet; 3. downstream systems distribute or use that packet; 4. attention, valuation, memory, decision, and report act on it; 5. a phenomenal bridge, if any, relates the packet to temporal experience.

A system can satisfy one stage without satisfying the others.

Neural failure modes

The model distinguishes:

  • **transport-model failure:** edge responses are not well described by additive scalar delays;
  • **route-consistency failure:** tested route differences have nonzero holonomy;
  • **support failure:** the projector leaks outside the predeclared front tube;
  • **capture failure:** phase responses are flat, unstable, or too narrow;
  • **retention failure:** the selected mode decays before \(N_{\mathrm{meta}}\);
  • **selection failure:** the cluster is unstable, \(q\) is near one, \(M\) is large, or no contour robustly isolates the mode;
  • **feature-closure failure:** the chosen phase-feature space is not approximately invariant;
  • **amplitude failure:** recorded signal amplitude is small despite preserved normalized geometry.

Only the first seven bear directly on the proposed mathematical mechanism. Low signal amplitude is not by itself a tokenization failure.

Philosophical Reinterpretation

Causal temporal tokenization

A localized event is represented as

\[ e=(v,\theta_v). \]

Given an exact chart \(a\), define its causal phase

\[ \phi_a(e)=\theta_v-a_v. \]

Under

\[ \theta_v\mapsto\theta_v+c_v, \qquad a_v\mapsto a_v+c_v, \]

the causal phase is unchanged.

Two event representations may be assigned to the same mathematical token when:

1. their causal phases agree within the capture width; 2. their responses enter the same selected front range; 3. the relevant route transports are consistent.

This is a propagation-adjusted equivalence relation. It is not external simultaneity, feature conjunction, object individuation, global availability, or phenomenal unity.

Temporal thickness as an operational surrogate

The framework uses two third-person timescales:

  • **capture thickness:** the phase interval \(\sigma\) over which perturbations enter a token;
  • **retention thickness:** the finite horizon over which the selected feature remains distinguishable from complementary dynamics.

These quantities may be useful operational surrogates for temporal integration. They do not reconstruct the phenomenological structures of lived duration, succession, retention, or protention. Treating them as a complete analysis of temporal consciousness would change the target rather than explain it.

Three targets that must not be conflated

1. **Causal temporal tokenization:** path-consistent propagation and selected feature retention. 2. **Perceptual or access integration:** feature binding, temporal-order discrimination, segmentation, memory, decision, or report. 3. **Phenomenal temporal unity:** the apparent presence of succession or duration to a subject.

The theorems concern only the first. \(\mathsf H_N\) links the first to selected aspects of the second. \(\mathsf H_P\) is required to reach the third.

Centering and subject boundaries

The CCT working draft argues that uncentered structure does not by itself determine a first-person center [@src-paper-mateo-orlov-8-local-reference-6]. The present formalism does not resolve that concern. It does not determine:

  • which support, if any, is a subject;
  • why one support rather than an overlapping support is privileged;
  • whether a token is present to anyone;
  • what qualitative character it has;
  • whether two isomorphic token systems have the same experience.

The support \(W\), scale \(T_F\), intervention policy, feature space, and spectral cluster are externally selected. A tree automatically has zero graph obstruction, so low \(h(W)\) cannot identify the correct subject or neural token without an independent support-selection principle.

Phenomenality and semantic use

Dessalles and Zalla propose a discriminative and evaluative role for phenomenal properties [@src-paper-mateo-orlov-8-arxiv-3]. A retained packet might support discrimination, but discrimination does not imply phenomenality.

Kirilyuk invokes dynamic multivaluedness, chaoticity, and localized states in support of broad claims about consciousness [@src-paper-mateo-orlov-8-arxiv-1]. Those claims are neither assumed nor derived here. The present graph obstruction and Riesz representation provide no route from localization alone to consciousness.

“Wavefront” is entirely classical in this paper. It is unrelated to quantum-state collapse. Consciousness-collapse models constitute a separate speculative research program with different dynamical commitments [@src-paper-mateo-orlov-8-arxiv-4].

Proposition 1. Circle-valued graph exactness

**Statement.** Let \(W\) be a finite connected graph and

\[ \tau\in C^1(W;\mathbb A_F). \]

The following are equivalent:

1. \(h(W)=0\); 2. there is \(a\in C^0(W;\mathbb A_F)\) with \(\tau=da\); 3. every signed cycle has zero holonomy; 4. every pair of signed paths with common endpoints has the same accumulated delay.

Moreover,

\[ h(\tau+dc)=h(\tau). \]

**Proof.**

If \(h(W)=0\), compactness gives a minimizing \(a\) with

\[ \|\tau-da\|_{\infty,T_F}=0, \]

so \(\tau=da\). The converse follows directly from the definition.

If \(\tau=da\), then a cycle sum telescopes:

\[ \sum_{j=0}^{m-1} (a_{v_{j+1}}-a_{v_j})=0. \]

Now suppose every cycle holonomy vanishes. Choose a root and spanning tree. Assign \(a\) recursively along tree edges so that \(da=\tau\) there. Every non-tree edge closes a fundamental cycle. Zero holonomy on that cycle implies \(da=\tau\) on the non-tree edge as well.

For paths \(p_1,p_2:u\leadsto v\), concatenate \(p_1\) with the reverse of \(p_2\). Zero holonomy of the resulting closed walk gives equality of their path sums. Conversely, compare a cycle with the empty path.

Finally,

\[ \begin{aligned} h(\tau+dc) &= \min_a\|\tau+dc-da\|_{\infty,T_F}\\ &= \min_a\|\tau-d(a-c)\|_{\infty,T_F}\\ &=h(\tau). \end{aligned} \]

∎

A tree has no cycle obstruction. This is a reason to predeclare or penalize support selection, not evidence that every tree supports a neural token.

Proposition 2. Čech descent under a valid cover condition

**Statement.** A global section of \(\mathscr S_\tau\) exists exactly when

\[ [\tau]=0\in H^1(W;\mathbb A_F). \]

For any cover admitting local charts, the overlap constants define a Čech descent cocycle whose vanishing is equivalent to gluing those local charts. If the cover is good or Leray for the constant coefficient sheaf, this Čech obstruction corresponds to the cellular class \([\tau]\).

**Proof.**

A global section is precisely an \(a\) satisfying \(da=\tau\), so it exists exactly when \(\tau\) is a coboundary.

On overlaps,

\[ d(a_\beta-a_\alpha)=0, \]

so \(g_{\alpha\beta}=a_\beta-a_\alpha\) is locally constant. The triple-overlap identity makes \(g\) a Čech \(1\)-cocycle. If \(g\) is a coboundary, constants can be subtracted from the local charts so that they agree on overlaps, producing a global chart. A global chart conversely trivializes \(g\).

The identification of this descent class with cellular \([\tau]\) uses the stated good- or Leray-cover comparison. It is not asserted for an arbitrary subgraph cover. ∎

Theorem 1. Full signed-path holonomy no-go

**Statement.** Assume ideal probe transport,

\[ \mathsf T_pp_u(r) = p_v\!\left( r+\sum_{e\in p}\epsilon_{p,e}\tau_e \right). \]

If an operator \(B\) satisfies full signed-path independence and \(r\mapsto Bp_u(r)\) is injective for every relevant vertex, then

\[ h(W)=0. \]

Conversely, if \(h(W)=0\), then ideal transport is path independent before projection, and therefore after application of any operator \(B\). If the projected probe curves are injective, the decoder equation A3 also follows.

**Proof.**

Let \(C\) be a signed cycle based at \(u\). Comparing \(C\) with the empty path gives

\[ Bp_u\!\left( r+\operatorname{Hol}_\tau(C) \right) = Bp_u(r). \]

Injectivity implies

\[ \operatorname{Hol}_\tau(C)=0 \quad\text{in }\mathbb A_F. \]

This holds for every cycle, so Proposition 1 gives \(h(W)=0\).

Conversely, if \(h(W)=0\), all paths with common endpoints have the same accumulated delay. Therefore

\[ \mathsf T_{p_1}p_u(r) = \mathsf T_{p_2}p_u(r) \]

before projection. Applying \(B\) preserves equality.

For an edge \(e=(u,v)\),

\[ B\mathsf T_ep_u(r) = Bp_v(r+\tau_e). \]

Applying the inverse decoder gives

\[ \delta_v^B(B\mathsf T_ep_u(r)) = r+\tau_e = \delta_u^B(Bp_u(r))+\tau_e. \]

∎

The theorem is a no-go result only for the stated representation: additive circle-valued transport, path identification, and phase-faithful outputs. A nonlinear, path-tagged, branching, directed-history-dependent, or non-Abelian mechanism may evade it by changing the target.

For an operational route set \(\mathcal R\), the same proof establishes only

\[ \langle\tau,z\rangle=0 \quad\text{for }z\in Z_{\mathcal R}. \]

Full \(h(W)=0\) follows only if \(Z_{\mathcal R}\) spans the cycle space.

Proposition 3. Spectral projector representation

**Statement.** Let \(B\) be a finite-rank nonzero projector satisfying

\[ \mathcal PB=B\mathcal P=\lambda B \]

and

\[ \operatorname{dist} \left( \lambda, \operatorname{spec}(\mathcal P|_{\ker B}) \right)>0. \]

Then \(\lambda\) is isolated in \(\operatorname{spec}(\mathcal P)\), and \(B\) is the Riesz projector for a sufficiently small contour around \(\lambda\).

Conversely, if a contour isolates a finite-rank spectral cluster on which

\[ \mathcal P\Pi=\Pi\mathcal P=\lambda\Pi, \]

then \(\Pi\) satisfies the projector and complementary-invariance part of A6. It satisfies the full A6 only if the decay and predeclared metastability inequalities also hold.

**Proof.**

Because \(B\) is a bounded projector,

\[ \mathscr H = \operatorname{Ran}B\oplus\ker B. \]

Commutation makes both summands invariant. Relative to this complementary invariant decomposition,

\[ \mathcal P = \begin{pmatrix} \lambda I&0\\ 0&\mathcal P_0 \end{pmatrix}. \]

The positive distance between \(\lambda\) and \(\operatorname{spec}(\mathcal P_0)\) permits a contour enclosing \(\lambda\) and no complementary spectrum. Resolvent integration yields identity on \(\operatorname{Ran}B\) and zero on \(\ker B\), hence the Riesz projector is \(B\).

The converse follows from standard Riesz functional calculus and the scalar action assumed on the selected range. The inequalities \(0<|\lambda|<1\) and

\[ |\lambda|^{N_{\mathrm{meta}}-1}\ge\eta_{\mathrm{meta}} \]

are additional conditions, not consequences of spectral isolation. ∎

Theorem 2. Conditional exact construction

**Statement.** Suppose:

1. \(h(W)=0\), with exact chart \(a\); 2. the aligned operator \[ \mathcal P_F=A_a\mathcal P_{\mathrm{lab}}A_a^{-1} \] has an isolated finite-rank scalar resonance \(\lambda_F\) with Riesz projector \(\Pi_F\); 3. \(0<|\lambda_F|<1\) and the predeclared metastability threshold holds; 4. with \[ S_a=A_aS_{W,\sigma}A_a^{-1}, \] the independent support identities hold: \[ \Pi_F=S_a\Pi_F=\Pi_FS_a; \] 5. for \[ B_F=A_a^{-1}\Pi_FA_a, \] the projected probe curves are injective and satisfy the declared local decoder bounds; 6. probes and support projections transform covariantly under clock changes.

Then \(B_F\) satisfies A1–A6 for the full signed-path class.

Conversely, every \(B_F\) satisfying A1–A6 for the full signed-path class has \(h(W)=0\), and in an exact chart its conjugate

\[ \Pi_F=A_aB_FA_a^{-1} \]

is the Riesz projector of an isolated finite-rank scalar resonance satisfying the conjugated support and timing conditions.

**Proof.**

Riesz calculus gives

\[ \Pi_F^2=\Pi_F. \]

Hence

\[ B_F^2 = A_a^{-1}\Pi_F^2A_a = B_F. \]

The support identities conjugate to

\[ B_F=S_{W,\sigma}B_F=B_FS_{W,\sigma}, \]

which is A1.

The scalar resonance equation gives

\[ \mathcal P_{\mathrm{lab}}B_F = B_F\mathcal P_{\mathrm{lab}} = \lambda_FB_F. \]

Isolation, decay, and the threshold give A6.

By Theorem 1, exactness of \(\tau\) makes the ideal transports path independent. Probe injectivity supplies the exact decoders, so A3–A5 follow.

For a gauge change \(c\),

\[ A_{a+c}U_c=A_a. \]

The aligned operator is unchanged after simultaneous transformation of the laboratory coordinates, so the Riesz projector in aligned coordinates is unchanged. Therefore,

\[ \begin{aligned} B_F^c &= A_{a+c}^{-1}\Pi_FA_{a+c}\\ &= U_cA_a^{-1}\Pi_FA_aU_c^{-1}\\ &= U_cB_FU_c^{-1}, \end{aligned} \]

which is A2.

If \(b=a+g\) is another exact chart for the same fixed coordinates, then

\[ \mathcal P_b=L_g\mathcal P_aL_g^{-1} \]

and

\[ \Pi_b=L_g\Pi_aL_g^{-1}. \]

Consequently,

\[ A_b^{-1}\Pi_bA_b = A_a^{-1}\Pi_aA_a. \]

Thus the laboratory projector is independent of global phase origin.

For the converse, Theorem 1 yields \(h(W)=0\). Proposition 3 shows that the aligned conjugate of \(B_F\) is the Riesz projector for the isolated resonance. A1 and A5 conjugate to the stated support and timing conditions. ∎

This theorem does not derive locality or timing fidelity from spectral isolation. It states precisely which independent conditions are jointly sufficient and which properties are recovered from an already admissible projector.

Counterexample to the unrevised spectral axiom

Let \(W\) have one vertex, let \(g\) be a normalized Fourier feature, and let \(B\) project onto \(\operatorname{span}\{g\}\). Choose probes satisfying

\[ Bp(r)=e^{2\pi ir/T_F}g. \]

Let

\[ \mathcal P=B+\mu(I-B), \qquad |\mu|<1, \quad \mu\ne1. \]

Then

\[ \mathcal PB=B\mathcal P=B \]

and the complementary spectral separation is \(|1-\mu|>0\). Locality and timing faithfulness can hold, while edge and path requirements are vacuous. Thus any axiom that required only an eigenprojector and complementary separation would admit \(\lambda_F=1\).

The current A6 excludes this example because it explicitly requires \(0<|\lambda_F|<1\). The example remains a valid stationary projector, but it is not an admissible decaying metastable resonance in the present terminology.

Proposition 4. Renormalized finite-horizon filter

**Statement.** If

\[ \mathcal P_F^k=\lambda_F^k\Pi_F+R^{(k)} \]

and

\[ \frac{\|\lambda_F^{-k}R^{(k)}\|}{\|\Pi_F\|} \le Mq^k, \]

then

\[ \boxed{ \frac{ \|\widehat\Pi_L-\Pi_F\| }{ \|\Pi_F\| } \le \frac{M(1-q^L)}{L(1-q)} \le \frac{M}{L(1-q)}. } \]

**Proof.**

Substitution gives

\[ \widehat\Pi_L-\Pi_F = \frac1L \sum_{k=0}^{L-1} \lambda_F^{-k}R^{(k)}. \]

Taking norms and summing the geometric series proves the result. ∎

If empirical iterates contain errors \(N_k\), the additional normalized error is bounded by

\[ \frac1{L\|\Pi_F\|} \sum_{k=0}^{L-1} |\lambda_F|^{-k}\|N_k\|. \]

Thus renormalization can exponentially amplify observation and model errors. The noiseless bound alone does not justify the renormalized filter as an estimator.

Corollary 4.1. Approximate idempotence and composition

Let

\[ \varepsilon_L=\|\widehat\Pi_L-\Pi_F\|. \]

Then

\[ \boxed{ \|\widehat\Pi_L^2-\widehat\Pi_L\| \le (2\|\Pi_F\|+1)\varepsilon_L+\varepsilon_L^2. } \]

For two horizons \(L,J\),

\[ \boxed{ \|\widehat\Pi_L\widehat\Pi_J-\Pi_F\| \le \|\Pi_F\|(\varepsilon_L+\varepsilon_J) +\varepsilon_L\varepsilon_J. } \]

**Derivation.**

Write

\[ \widehat\Pi_L=\Pi_F+\mathcal E_L. \]

Expanding the products and using \(\Pi_F^2=\Pi_F\) gives the stated inequalities. No orthogonality is assumed. A large \(\|\Pi_F\|\) indicates sensitivity associated with a nonorthogonal spectral decomposition.

Proposition 5. Amplitude-unrenormalized filter

Let

\[ \lambda_F=e^{-\kappa+i\omega}, \qquad b=qe^{-\kappa}, \]

and

\[ \alpha_L = \frac1L \sum_{k=0}^{L-1}e^{-\kappa k}. \]

Then

\[ \boxed{ \frac{ \|\widetilde\Pi_L-\Pi_F\| }{ \|\Pi_F\| } \le 1-\alpha_L + \frac{M(1-b^L)}{L(1-b)}. } \]

Furthermore,

\[ 1-\alpha_L \le \frac{\kappa(L-1)}2 \]

and therefore

\[ \boxed{ \frac{ \|\widetilde\Pi_L-\Pi_F\| }{ \|\Pi_F\|} \le \frac{M}{L(1-b)} + \frac{\kappa(L-1)}2. } \]

**Proof.**

On the selected range,

\[ e^{-ik\omega}\lambda_F^k=e^{-\kappa k}. \]

Hence

\[ \widetilde\Pi_L = \alpha_L\Pi_F + \frac1L \sum_{k=0}^{L-1} e^{-ik\omega}R^{(k)}. \]

The power assumption implies

\[ \|R^{(k)}\| \le M\|\Pi_F\||\lambda_F|^kq^k = M\|\Pi_F\|b^k. \]

The first bound follows by the triangle inequality and geometric summation. For the second,

\[ 1-e^{-\kappa k}\le\kappa k, \]

so

\[ 1-\alpha_L \le \frac{\kappa}{L} \sum_{k=0}^{L-1}k = \frac{\kappa(L-1)}2. \]

∎

The term \(1-\alpha_L\) is the actual bound contributed by amplitude decay. The linear expression is only an upper envelope.

Theorem 3. Calibrated approximate-binding bounds

**Statement.** Assume:

1. \(\mathcal A_\sigma\ne\varnothing\); 2. a minimizer \(a^*\) of \(h(W)\) belongs to \(\mathcal A_\sigma\); 3. the calibrated local bi-Lipschitz response bounds hold; 4. the same operator and spectral cluster are used under all chart conjugacies; 5. the normalized power estimate holds with constants \(M,q\).

Then

\[ \boxed{ D_L \ge c_h\frac{h(W)}{\sigma} } \]

and

\[ \boxed{ D_L \le C_h\frac{h(W)}{\sigma} + 1-\alpha_L + \frac{M(1-b^L)}{L(1-b)}. } \]

Consequently,

\[ D_L \le C_h\frac{h(W)}{\sigma} + \frac{M}{L(1-b)} + \frac{\kappa(L-1)}2. \]

**Proof.**

For every admissible chart,

\[ \Delta_h(a) \ge c_h \frac{ \max_e|\rho_e(a)| }{\sigma} \ge c_h\frac{h(W)}{\sigma}. \]

Since \(G_L(a)\ge0\), taking the infimum gives the lower bound.

For the minimizing chart \(a^*\),

\[ \Delta_h(a^*) \le C_h\frac{h(W)}{\sigma}. \]

Proposition 5 bounds \(G_L(a^*)\). Evaluating the infimum at \(a^*\) proves the upper bounds. ∎

The lower bound follows from the deliberately additive diagnostic and the assumed local lower Lipschitz constant. It is not a lower bound on an independently defined behavioral loss.

Proposition 6. Exact discrete horizon and envelope-optimal horizon

Define the exact certified dynamic bound

\[ g_L = 1-\alpha_L + \frac{M(1-b^L)}{L(1-b)}. \]

For an available lifetime \(1\le L\le N_F\), the exact certified horizon is

\[ \boxed{ L_{\mathrm{cert}} \in \operatorname*{arg\,min}_{L\in\{1,\ldots,N_F\}} g_L. } \]

No closed-form continuous expression is asserted for this discrete minimum.

A looser envelope is

\[ f(L) = \frac{A_b}{L}+\frac{\kappa L}{2}, \qquad A_b=\frac{M}{1-b}. \]

For \(\kappa>0\), its continuous minimizer is

\[ \boxed{ L_{\mathrm{env}} = \sqrt{\frac{2A_b}{\kappa}} = \sqrt{ \frac{2M}{ \kappa(1-qe^{-\kappa}) } }. } \]

The minimum envelope value is

\[ \boxed{ f(L_{\mathrm{env}}) = \sqrt{2A_b\kappa}. } \]

**Proof.**

The exact statement is finite minimization. For the envelope,

\[ f'(L)=-\frac{A_b}{L^2}+\frac{\kappa}{2}, \qquad f''(L)=\frac{2A_b}{L^3}>0. \]

The stationary point is therefore the unique global minimum. ∎

The implementable envelope optimizer is obtained by clipping \(L_{\mathrm{env}}\) to \([1,N_F]\) and checking the neighboring integers. It optimizes a conservative bound, not the exact filter error or a general neural loss. The stationary boundary \(\kappa=0\) lies outside A6; in that generalized case the decay term vanishes and longer horizons weakly improve the stated bound.

Proposition 7. Visible-competitor lower bound

**Statement.** Suppose:

1. \(\|\Pi_F\|=1\); 2. \(x\in\operatorname{Ran}\Pi_F\) and \(y\in\ker\Pi_F\) are normalized; 3. for \(q\in[0,1)\), \[ \mathcal P_Fx=\lambda_Fx, \qquad \mathcal P_Fy=q\lambda_Fy. \]

Then

\[ \boxed{ \|\widetilde\Pi_L-\Pi_F\| \ge \max\{1-\alpha_L,\beta_L\}, } \]

where

\[ \beta_L = \frac1L \sum_{k=0}^{L-1} (qe^{-\kappa})^k. \]

**Proof.**

On \(x\),

\[ \widetilde\Pi_Lx=\alpha_Lx, \qquad \Pi_Fx=x. \]

Thus the error norm is at least \(1-\alpha_L\). On \(y\),

\[ \widetilde\Pi_Ly=\beta_Ly, \qquad \Pi_Fy=0, \]

so it is also at least \(\beta_L\). ∎

For \(L\le N_F\),

\[ \beta_L \ge (qe^{-\kappa})^{N_F-1}. \]

For \(L\ge2\),

\[ 1-\alpha_L \ge \frac12(1-e^{-\kappa}), \]

while at \(L=1\), \(\beta_1=1\). Hence every admissible horizon satisfies

\[ \|\widetilde\Pi_L-\Pi_F\| \ge \min\left\{ 1,\frac12(1-e^{-\kappa}) \right\}. \]

This is a genuine lower bound only under the specified visible, phase-coherent complementary eigenmode. It does not cover generalized eigenvectors, continuous spectrum, differently rotating competitors, or modes invisible to the probes.

Proposition 8. Conditional uniqueness and passive nonidentifiability

Assume the exact operator, function space, support, and cluster have already been supplied.

1. **Conditional projector uniqueness.** A contour isolating a specified cluster determines one Riesz projector. 2. **Chart uniqueness up to global phase.** If \(da=db=\tau\) on connected \(W\), then \(a-b\) is constant. 3. **Laboratory-projector independence of chart origin.** Conjugating both the aligned operator and its Riesz projector under a global phase shift leaves \[ A_a^{-1}\Pi_aA_a \] unchanged. 4. **No canonical cluster selection.** Several front-supported isolated clusters may exist. Riesz uniqueness after cluster selection is not a rule for choosing among them. 5. **Degenerate range.** If the selected range has rank \(r>1\) and scalar action \(\lambda I\), the range is fixed but no preferred basis is selected. 6. **Passive nonidentifiability.** Stationary covariance, nodewise autocovariance, and pairwise cross-spectral magnitudes need not identify propagation direction.

For the last claim, consider

\[ x_{n+1}=\alpha Ux_n+\eta_n, \qquad 0<\alpha<1, \]

where \(U\) is an orthogonal cyclic shift and

\[ \eta_n\sim\mathcal N(0,(1-\alpha^2)I). \]

The systems with \(U\) and \(U^{-1}=U^\top\) both have stationary covariance \(I\). Their lag-covariance sequences are transposes under direction reversal. For a circulant shift, nodewise autocovariances match, and the cross-spectral matrices are transposed/conjugated, so pairwise cross-spectral magnitudes match. Their directed interventional responses propagate oppositely.

These are algebraic uniqueness and nonidentifiability results. They are not statistical recovery guarantees from finite data.

Proposition 9. Exact and approximate graph algorithms

Let

\[ n=|V_W|, \qquad m=|E_W|, \qquad \beta=m-n+1. \]

#### Exact consistency

Choose a spanning tree, fix one root phase, and assign all other phases along tree edges. Test every non-tree edge by

\[ \operatorname{wrap}_{T_F} \left( \tau_e-(a_v-a_u) \right)=0. \]

All tests pass exactly when all fundamental-cycle holonomies vanish. The arithmetic-operation complexity is

\[ \boxed{O(n+m)}. \]

This assumes exact circle values.

#### Approximate consistency

Choose principal lifts

\[ \widetilde\tau_e\in(-T_F/2,T_F/2]. \]

Use real node variables \(x_v\), integer edge windings \(z_e\), and residual radius \(\delta\):

\[ -\delta \le \widetilde\tau_e-(x_v-x_u)-z_eT_F \le \delta. \]

Fix one root lift. Integer shifts of node lifts can set all tree-edge windings to zero. Only the \(\beta\) non-tree winding variables remain.

A globally optimal solution always has

\[ \delta^*\le T_F/2, \]

because the constant chart achieves that bound. For a non-tree edge \(e\), let \(C_e\) be its fundamental cycle. Summing residual equations around \(C_e\) gives

\[ \widetilde H_e-k_eT_F = \sum_{f\in C_e}\epsilon_{e,f}\rho_f, \]

where

\[ |\widetilde H_e| \le |C_e|T_F/2 \]

and

\[ \left| \sum_{f\in C_e}\epsilon_{e,f}\rho_f \right| \le |C_e|T_F/2. \]

Therefore an optimum exists with

\[ |k_e|\le |C_e|. \]

Let

\[ K=\max_{e\notin T}|C_e|. \]

Enumerating

\[ k_e\in\{-|C_e|,\ldots,|C_e|\} \]

is therefore complete, not a post hoc truncation. Each winding sector is a linear program with \(n+1\) real variables and \(2m\) principal inequalities. With input bit length \(b_{\mathrm{in}}\), the complexity is bounded by

\[ \boxed{ (2K+1)^\beta \operatorname{poly}(n,m,b_{\mathrm{in}}). } \]

This is fixed-parameter tractable in the pair \((\beta,K)\), not in cycle rank alone. Since \(K\) may grow with graph size, no unrestricted polynomial-time claim follows.

Countermodel or Null System

Countermodel 1. Frustrated triangle and information-erasing substitutes

Let \(T_F=1\) and

\[ 1\to2\to3\to1 \]

have

\[ \tau_{12}=\tau_{23}=\tau_{31}=\frac16. \]

Then

\[ \operatorname{Hol}_\tau(C)=\frac12\ne0 \quad\text{in }\mathbb R/\mathbb Z. \]

The constant chart leaves residual \(1/6\) on every edge, so \(h(W)\le1/6\). If all residual magnitudes were strictly below \(1/6\), their cycle sum could not represent a half-period holonomy. Hence

\[ \boxed{h(W)=\frac16.} \]

No full signed-path, phase-faithful token projector exists.

A zero map, phase-average projector, or holonomy-group average can nevertheless make outputs path invariant by erasing the distinctions that reveal the inconsistency. For example,

\[ \mathcal G=\frac12(I+R_{1/2}) \]

identifies phases separated by half a period. It does not resolve the delay frustration; it quotients it away and violates timing fidelity.

Constructive null system 2. Killed excitable ring with a derived spectral mode

Consider states

\[ \{F_0,\ldots,F_{N-1},\partial\}, \]

where \(F_j\) is a single propagating pulse and \(\partial\) is a dead state. Let

\[ F_j\to \begin{cases} F_{j+1\ \mathrm{mod}\ N},&\text{with probability }1-p,\\ \partial,&\text{with probability }p, \end{cases} \]

and \(\partial\to\partial\), with \(0<p<1\).

On the full finite-dimensional observable space, the Koopman operator is

\[ (\mathcal Kf)(F_j) = (1-p)f(F_{j+1})+pf(\partial), \qquad (\mathcal Kf)(\partial)=f(\partial). \]

Define

\[ g_k(F_j)=e^{2\pi ikj/N}, \qquad g_k(\partial)=0. \]

Then

\[ \mathcal Kg_k = (1-p)e^{2\pi ik/N}g_k. \]

Thus the spectral mode is derived from the killed ring process rather than added as an unrelated subsystem. For \(k=1\),

\[ \lambda_1=(1-p)e^{2\pi i/N} \]

is isolated on this finite feature space. It is episode-metastable when \(p\) satisfies the predeclared retention threshold.

Let one propagation step last \(\Delta\), with

\[ T_F=N\Delta, \qquad \tau_{j,j+1}=\Delta, \qquad a_j=j\Delta\pmod{T_F}. \]

The cycle sum is \(T_F=0\) in \(\mathbb A_F\), so \(h(W)=0\). A probe family whose projection onto \(g_1\) is

\[ \Pi_1p_j(r)=e^{2\pi ir/T_F}g_1 \]

is phase faithful.

The process has pulse position, survival, and death variables. It need not have semantic categories, self-modeling, flexible report, valuation, or executive control. This does not prove that the ring lacks phenomenality; the formalism contains no phenomenal-absence criterion.

Null system 3. Maximal synchrony without sufficient front evidence

Let

\[ \theta_j(t)=\Omega t \]

for all \(j\). The Kuramoto order parameter is one. If all recorded channels are copies of the same waveform, pairwise phase locking and nodewise spectra can be maximal while the observable state manifold contains only one global phase degree of freedom.

For a predeclared proper front-tube projection \(S_{W,\sigma}\), the only global synchronized mode need not satisfy

\[ \Pi=S\Pi=\Pi S. \]

Nor do passive synchronous observations identify edge delays or propagation direction. Synchronizability itself depends on network direction, weighting, and heterogeneity [@src-paper-mateo-orlov-8-arxiv-16].

This null establishes only that maximal synchrony does not entail the proposed front token. It does not establish that synchronized systems can never contain an independently identified propagating subspace.

Null system 4. Autonomous mixing dynamics without a front projector

Let

\[ x_{n+1}=Ax_n\pmod1 \]

be a mixing hyperbolic toral automorphism on \(\mathbb T^d\). Its Koopman operator maps Fourier functions by

\[ \mathcal Ue_k=e_{A^\top k}. \]

For \(k\ne0\), the Fourier orbit is infinite. Mixing excludes nonconstant \(L^2\) eigenfunctions, and the constant eigenvalue is not a front-supported decaying resonance.

The system is autonomous, high dimensional, and perturbation sensitive, yet it supplies no propagation graph, arrival chart, or front tube. Therefore autonomy or a broad notion of causal closure does not imply a wavefront token. This is a one-way non-implication. The killed ring is also autonomous, so the two examples do not establish logical independence between tokenization and a separately formalized closure criterion.

Countermodel 5. Noncommuting front projectors

Let

\[ \Pi_+ = \begin{pmatrix} 1&0\\ 0&0 \end{pmatrix}, \qquad u= \begin{pmatrix} \cos\vartheta\\ \sin\vartheta \end{pmatrix}, \qquad \Pi_-=uu^\top, \]

with \(0<\vartheta<\pi/2\). Then

\[ [\Pi_+,\Pi_-]\ne0. \]

Sequential application is order dependent:

\[ \Pi_+\Pi_-\ne\Pi_-\Pi_+. \]

This proves only that these two projector operations do not define an order-independent sequential tokenization on their overlap. It does not prove that no enlarged representation, joint instrument, POVM, path-tagged state, or higher-order segmentation scheme exists.

Null system 6. Exact gluing without spectral selection

Let \(W\) have an exact chart, so \(h(W)=0\), but let the aligned apparent wave lie in continuous spectrum or a dense resonant cluster. Then all ideal path delays are consistent, yet no contour robustly isolates a finite-rank front projector.

Exact delay gluing therefore supplies a coherent coordinate, not a dynamically selected token.

Null system 7. Spectral mode without timing fidelity

Let \(\Pi\) be an isolated rank-one Riesz projector onto a phase-independent feature. Then

\[ \Pi p_v(r)=g \]

for all \(r\). The mode may be local, decaying, and spectrally robust, but it cannot decode temporal phase and fails A5.

This shows directly why an isolated resonance is insufficient without independently verified probe discrimination.

Empirical Boundary Conditions and Falsification Criteria

Predeclared model-selection boundary

The following must be fixed before confirmatory testing, selected on training data, or included in the null search:

  • support and grain \(W\);
  • episode scale \(T_F\);
  • maximum history depth \(D\);
  • intervention policy and response lag;
  • phase-feature dictionary;
  • front tube \(S_{W,\sigma}\);
  • capture calibration and decoder;
  • spectral-cluster selection rule;
  • contour-stability criterion;
  • minimum metastability horizon and retained fraction.

Deleting edges until \(W\) is a tree always removes graph holonomy. Searching supports without correction can therefore force a trivial consistency result. The same problem arises when \(T_F\) is optimized after inspecting cycle sums.

Statistical null for graph consistency

A null distribution for the fitted obstruction should repeat the entire support, scale, and winding search while preserving relevant low-level statistics. Suitable surrogate families may preserve:

  • graph degree and edge-length strata;
  • marginal delay distributions;
  • nodewise autocorrelation and spectra;
  • intervention timing and energy;
  • timestamp-error covariance;
  • numbers and lengths of tested routes.

They should destroy directed cycle consistency, for example by:

  • permuting delays within anatomical or distance strata;
  • reversing intervention direction where experimentally meaningful;
  • permuting intervention labels;
  • shifting response epochs independently across nodes;
  • generating common-drive models with matched marginals.

The confirmatory statistic is not simply \(\widehat h(W)\). It is the search-corrected improvement over these nulls, with confidence intervals that include circular unwrapping uncertainty.

Spectral nulls

A spectral null should preserve stationary spectra and autocorrelation while destroying front-relative propagation. Candidate nulls include:

  • time-reversed transition models;
  • phase-randomized multichannel surrogates;
  • common-input state-space models;
  • static phase-gradient models;
  • recurrent non-wave models;
  • colored nonnormal systems producing long transients;
  • hidden-node models that mimic apparent route delays.

The analysis should compare:

\[ \lambda_F,\quad \Pi_F,\quad \|\Pi_F\|,\quad M,\quad q,\quad \epsilon_{\mathrm{cl}} \]

against the corresponding null distributions. Projector stability should be quantified by bootstrap subspace distances and contour perturbations, not merely by the visual persistence of eigenvalues.

Held-out interventional tests

A candidate model should predict held-out response distributions under interventions varying:

  • vertex;
  • causal phase;
  • laboratory time;
  • intervention amplitude;
  • route direction;
  • episode context.

At minimum, it should be compared against:

1. common-drive models; 2. conventional evoked-response models; 3. static phase-gradient models; 4. recurrent but nonpropagating models; 5. latent-node or omitted-pathway models; 6. synchrony-only predictors.

Support for \(\mathsf H_M\) requires low route obstruction and stable spectral selection on held-out data. Support for \(\mathsf H_N\) additionally requires improved prediction of downstream grouping or integration.

Mathematical refutation criteria

The mathematical results would be refuted by:

1. a counterexample to Proposition 1 on a finite graph with the stated circle-valued cochain conventions; 2. a phase-injective, fully signed-path-independent operator on a graph with nonzero cycle holonomy while ideal transport holds; 3. failure of Proposition 3 under the stated complementary invariant decomposition and spectral separation; 4. violation of a finite-horizon bound while its power assumptions hold; 5. violation of Theorem 3 while calibration, local bi-Lipschitz response, chart admissibility, and common-cluster assumptions all hold.

These are mathematical refutations or assumption violations, not empirical falsification criteria.

Falsification of \(\mathsf H_M\)

The proposed neural mechanism should be rejected for a declared regime if any of the following persists after uncertainty correction:

  • the scalar additive edge-delay model fails held-out interventions;
  • route holonomies remain inconsistent;
  • tested routes do not identify the cycle space claimed in the interpretation;
  • the candidate projector violates the predeclared support mask;
  • phase decoding is noninjective or unstable;
  • the feature space has large closure residual;
  • the resonance fails the predeclared metastability threshold;
  • apparent isolation disappears under resampling or matched nonnormal nulls;
  • front-relative phase does not predict projected responses beyond conventional alternatives.

Changing \(W\), \(T_F\), the feature dictionary, or \(\Gamma\) after a negative result constitutes a new hypothesis and requires new held-out data.

Falsification of \(\mathsf H_N\)

The neurocognitive tokenization hypothesis should be rejected for a task if, despite support for \(\mathsf H_M\):

  • causal-phase membership does not improve held-out prediction of temporal grouping;
  • destroying front direction or route consistency leaves performance unchanged;
  • common drive, synchrony, static gradients, or conventional recurrent models explain the same outcomes equally well;
  • the estimated token precedes or follows behavior in a way incompatible with the proposed causal role;
  • perturbations that selectively disrupt the token do not selectively affect the predicted integration measure.

Temporal-order judgments, multisensory windows, segmentation, and report are legitimate outcomes for \(\mathsf H_N\), but they remain influenced by attention, memory, decision, and motor preparation.

Evaluation of \(\mathsf H_P\)

A specified phenomenal bridge can be disconfirmed if it predicts a stable relationship between front tokens and convergent report or no-report measures that repeatedly fails under matched conditions. However:

  • success would not establish that the token is phenomenal;
  • failure could reflect an incorrect bridge, an inadequate measure, or a failure of \(\mathsf H_M\);
  • behavioral temporal integration does not uniquely measure phenomenal temporal unity;
  • finding the token during unconscious processing would refute sufficiency for consciousness, not its possible use in conscious processing.

The phenomenal target therefore remains underdetermined rather than operationally settled.

Limitations

Mathematical limitations

1. **Restricted transport model.** One additive circle value per edge cannot represent broad, multimodal, state-dependent, amplitude-dependent, or history-dependent delays. 2. **Restricted path target.** Ordinary graph cohomology corresponds to all signed paths. Neural route comparisons may generate only a proper subgroup of the cycle space. 3. **Externally selected support.** \(W\), \(T_F\), and the front tube are inputs. The theory does not identify the correct neural token or subject boundary. 4. **Tree triviality.** Every cochain on a tree is exact, so graph exactness alone rewards support pruning. 5. **Independent locality and timing assumptions.** Spectral isolation does not imply front support or phase discrimination. 6. **Scalar semisimplicity.** The selected range is assumed to carry \(\lambda_FI\). Jordan blocks introduce polynomial factors and alter all filter bounds. 7. **Real-signal pairing.** Nonreal resonances require conjugate-pair reconstruction for real neural signals. 8. **Nonnormality.** Spectral distance \(\gamma_F\) does not control \(M\), \(q\), projector norm, or pseudospectral growth without additional resolvent estimates. 9. **Feature-space dependence.** The Koopman spectrum depends on state augmentation, policy, invariant measure, observable dictionary, norm, and regularization. 10. **Exact invariance.** The operator construction assumes an invariant feature subspace. Approximate closure requires an additional error analysis. 11. **Local decoder bound.** The linear lower bound excludes phase-insensitive and locally quadratic response profiles. 12. **Diagnostic additivity.** \(D_L\) is defined to prevent cancellation. Its lower bound is not automatically a lower bound on prediction error or behavior. 13. **Envelope optimization.** \(L_{\mathrm{env}}\) minimizes a loose upper envelope. The exact certified horizon is the discrete minimizer of \(g_L\), and neither necessarily minimizes empirical loss. 14. **Noise amplification.** Renormalized filtering can amplify measurement errors by \(|\lambda_F|^{-k}\). 15. **Visible-competitor restriction.** The dynamic lower bound applies only to a specified phase-coherent complementary eigenvector. 16. **Branching and collision.** A single chart cannot represent source switching, annihilation, branching, or multiple counterpropagating fronts. 17. **Finite-episode stationarity.** Riesz projectors belong to stationary operator theory, whereas neural episodes are finite and nonstationary. 18. **Computational scaling.** The approximate graph algorithm is fixed-parameter tractable in \((\beta,K)\), not generally polynomial in all inputs.

Statistical and identifiability limitations

1. Exact operator uniqueness after cluster selection is not statistical identifiability from finite data. 2. Hidden nodes may create or remove apparent cycle frustration after marginalization. 3. Common input and filtering can mimic directionality. 4. Absolute arrival phases are gauge dependent. 5. Several isolated front-supported clusters may coexist. 6. A degenerate spectral range has no privileged basis. 7. Finite samples may confuse a resonance with a nonnormal transient. 8. Search over support, scale, feature space, contour, and decoder creates severe multiple-testing risk. 9. Delay estimates require correlated circular-error models and latent winding inference. 10. Interventions may not span the feature space needed to identify the operator. 11. Time-varying intervention policies generate an indexed operator family rather than one stationary operator. 12. The required matched nulls may themselves be misspecified.

Neuroscientific limitations

The cited neural sources do not establish \(h(W)\), \(S_{W,\sigma}\), \(\Pi_F\), \(M\), \(q\), or a relationship between these quantities and consciousness. Connectome-directed waves motivate propagation geometry [@src-paper-mateo-orlov-8-crossref-11]. Delay and phase-response work motivates effective timing models [@src-paper-mateo-orlov-8-crossref-8]. Audio-visual inter-trial coherence motivates phase-sensitive integration experiments [@src-paper-mateo-orlov-8-crossref-9]. None verifies the proposed mechanism.

Effective neural delays may vary with state, frequency, amplitude, adaptation, intervention strength, and route history. The scalar cochain should therefore be rejected before holonomy is interpreted if additivity fails held-out tests.

The framework also does not explain how a biological network selects its scale, support, feature representation, or spectral cluster. It does not establish that wavefront tokenization is used across modalities, species, sleep states, anesthesia, or disorders of consciousness.

Philosophical limitations

No theorem derives:

  • a subject boundary;
  • a first-person center;
  • phenomenal presence;
  • qualitative character;
  • affect or value;
  • semantic content;
  • report;
  • a necessary or sufficient condition for consciousness.

The operational notions of capture and retention are not a complete phenomenology of lived time. A bridge from these quantities to phenomenal temporal unity requires independent argument and remains empirically underdetermined.

The MRCG and CCT documents are speculative AI-generated drafts [@src-paper-mateo-orlov-8-local-reference-7] [@src-paper-mateo-orlov-8-local-reference-6]. They are not authorities for correctness, novelty, or empirical plausibility.

The stored records do not provide a comprehensive technical literature on angular synchronization, gain graphs, graph Hodge theory, sheaf cohomology, transfer-operator metastability, coherent sets, dynamic mode decomposition, or perturbational neural-wave analysis. The manuscript therefore makes no priority claim for its standard mathematical components. Its comparative literature base is sufficient only for limited motivation and source-specific qualification.

Ethical limitation

The presence of the proposed projector must not be used as a stand-alone attribution of consciousness, moral status, competence, or clinical prognosis. Its absence must not be used to deny experience. This restriction is especially important for infants, nonhuman animals, people with disorders of consciousness, and artificial systems.

The killed-ring example shows that the formal operator does not logically imply report, semantics, self-modeling, or executive control. It does not license the claim that simple systems lack experience. Conversely, sophisticated verbal behavior neither demonstrates the operator nor independently settles phenomenality.

Conclusion

The revised theory establishes two separate conditional results.

First, additive circle-valued delay transport on a fixed graph has a global propagation-adjusted phase exactly when

\[ \tau=da, \qquad h(W)=0. \]

For the full signed-path category, this is equivalent to zero holonomy on every cycle. A phase-faithful operator cannot make transported outputs path independent when that condition fails. For a restricted neural route set, only holonomies generated by operationally comparable routes are constrained; ordinary graph \(H^1\) is justified only when those routes span the cycle space.

Second, a declared finite-rank token projector is a Riesz projector when it is an invariant scalar eigenspace separated from complementary spectrum. Spectral isolation alone does not create a binder. The exact construction additionally requires an independently fixed front tube, phase-faithful intervention probes, formal decoders, ideal additive transport, decay, and a predeclared metastability threshold. Under those conditions,

\[ B_F=A_a^{-1}\Pi_FA_a \]

is clock-gauge covariant and independent of the arbitrary global phase origin.

The finite-horizon results are approximation lemmas, not an intrinsic neural lifetime–gap law. The renormalized filter obeys

\[ \frac{ \|\widehat\Pi_L-\Pi_F\| }{ \|\Pi_F\|} \le \frac{M(1-q^L)}{L(1-q)}, \]

while the amplitude-unrenormalized filter obeys

\[ \frac{ \|\widetilde\Pi_L-\Pi_F\| }{ \|\Pi_F\|} \le 1-\alpha_L + \frac{M(1-(qe^{-\kappa})^L)} {L(1-qe^{-\kappa})}. \]

With calibrated local phase sensitivity,

\[ \frac{c_hh(W)}{\sigma} \le D_L\le \frac{C_hh(W)}{\sigma} + 1-\alpha_L + \frac{M(1-(qe^{-\kappa})^L)} {L(1-qe^{-\kappa})}. \]

The exact certified horizon is the integer minimizing this finite expression over the available episode. The square-root formula

\[ L_{\mathrm{env}} = \sqrt{ \frac{2M}{ \kappa(1-qe^{-\kappa}) } } \]

optimizes only a conservative envelope. The parameter \(q\) is an assumed relative power-decay factor, and its relation to spectral separation is not fixed without stronger normality or resolvent assumptions.

The countermodels delimit the interpretation. Frustrated delays can be hidden only by erasing timing distinctions. A simple killed ring can realize the formal structure without report or self-modeling. Maximal synchrony does not identify propagation. Autonomous mixing dynamics need not contain a front projector. Exact delay gluing need not produce spectral selection, and spectral selection need not preserve phase.

Empirically, the proposal is credible only if support, scale, observable space, decoder, and cluster selection are predeclared or search-corrected; delay uncertainty is modeled circularly and jointly; matched graph and spectral nulls are used; and causal-phase predictions generalize to held-out interventions. Those tests address a mathematical and neurocognitive hypothesis of temporal tokenization.

Whether such tokens contribute to conscious temporal unity remains a separate phenomenal bridge hypothesis. The present framework neither derives that bridge nor substitutes behavioral temporal integration for phenomenality.
