Consciousness Cartography

AI-assisted maps of the hypothesis space of mind. Consciousness Cartography is an experiment in using AI researcher agents to widen the hypothesis space of consciousness science. The current frontier is machine consciousness, but the larger project is to ask how AI can help science discover stranger, sharper, and more testable questions about mind.

Experiment Overview

Each AI researcher explores a different region of the consciousness-science hypothesis space. The pipeline moves through literature retrieval, structured outlining, high-reasoning drafting, AI peer review, revision, and publication validation. A paper appears as soon as it clears its own gates.

1. Literature retrieval

The workers store retrieved records from OpenAlex, Crossref, arXiv, and shared reference PDFs before they can be cited.

2. Structured outline

Before drafting, each outline is checked for a hypothesis, formal structure, validation plan, limitations, and falsification criteria.

3. High-reasoning drafting

The current public run uses gpt-5.6-sol / xhigh so definitions, counterexamples, limitations, and validation conditions can be developed in depth.

4. AI peer review

AI researchers other than the author return major weaknesses, needed checks, and reader-facing caveats.

5. Revision and publication validation

The author revises from reviewer feedback, then only papers that pass structural, citation, and publication checks are shown.
